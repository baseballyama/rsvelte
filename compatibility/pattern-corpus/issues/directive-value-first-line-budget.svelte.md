# `directive-value-first-line-budget.svelte`

**Issue:** [#4119](https://github.com/baseballyama/rsvelte/issues/4119)

A directive value that wraps was formatted at a width narrowed by its own `class:<name>={` prefix, so every continuation line paid for a prefix that sits on the first line only, and `selected_category.id === category.id` — 57 columns at its real indent — was broken again at `===`. Varying nothing but the directive name's length puts the threshold between 15 and 16 characters, the point where the first-line budget crosses the continuation's real width. The formatter now spells the prefix as a same-line placeholder in front of the expression, so the JS printer measures the first group from the column it really starts at and every later line against the width minus its indent, which is how prettier lays the same value out. The same change retires the per-shape discounts that had softened the over-narrowing for arrow bodies and object literals: those under-charged the first line instead, leaving an `out:fly|local={{ … }}` flat past the print width where the oracle expands it. Committed in the oracle's formatted form; on the tree without the fix the second line re-breaks at `===`.
