# `an-enum-declaration-carries-its-members.svelte`

**Issue:** parse-ast probe

`TSEnumDeclaration` was emitted as a bare envelope on **two** paths — a typed `JsNode` variant for a statement and an inline `Value` for a declaration — so it was a two-ports pair before it was a missing-children defect, and filling one in would have made it an eleventh entry in `two-ports-inventory.md` rather than closing anything. Both now go through one builder, and the variant joins the opaque `value: Box<Value>` group the other retained TS declarations use, which lets the envelope drop its dedicated tag for the generic `write_json_node` escape (`VERSION` 7 -> 8: removing a tag keeps dispatch generic but still changes the object a JS caller receives). The file carries `const enum`, `declare enum` and `export enum` because those are three different things: `const` and `declare` are separate acorn-typescript flags emitted in that order and **neither is in the ratchet**, and `export` is the second emitter — an enum reached through `ExportNamedDeclaration.declaration` rather than as a statement. A quoted member name is a `Literal` with its `raw`, and an implicit member value has **no** `initializer` key at all rather than a null one. Measured: 4 keys per axis pre-fix, 0 post-fix; the 4,898-unit x 2-axis sweep removes exactly the four ratcheted keys with 0 added and 0 count-moved; compile output byte-identical over 14,694 pairs; NAPI two-surface round trip 16/16, and 4/16 when the decoder is ablated to drop `members`. Not carried: acorn-typescript **rejects** a computed member key, so rsvelte accepting `enum E { ['C'] = 1 }` is an over-acceptance rather than a field divergence.
