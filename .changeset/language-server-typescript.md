`rsvelte lsp` now offers TypeScript's features in Svelte components, such as hover and completion, from the TypeScript 7.1 that `rsvelte typecheck` runs. `--no-typescript` turns them off. The Visual Studio Code extension leaves them to the Svelte extension where you install that one, unless `rsvelte.typescript` says otherwise.
