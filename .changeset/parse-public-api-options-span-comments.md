Make the public `parse()` API match official's on three counts. `modern` and `loose` were declared nowhere at the NAPI boundary, so the binding always returned the modern AST and never recovered from a parse error — official defaults `modern` to `false`, which means the **default return shape changes to the legacy AST**, as it already is upstream. `Root.end` stopped at the last non-whitespace byte instead of `source.length`; that could not be fixed alone, because the fixture runners read their input untrimmed while upstream's `test.ts` trims it, and the two deviations were cancelling on the 62 of 110 upstream parser fixtures whose input ends in whitespace. And JS comments never reached the nodes they belong to: the walk that harvests `svelte-ignore` texts is upstream's `add_comments` and now also records `leadingComments` / `trailingComments`, template expressions go through that same walk instead of an ad-hoc leading/trailing/interior split with no last-in-body or separator rule, and a script's walk inherits the comments an earlier script parse recorded — which is what makes a `<script module>` comment bind to the instance script's first statement, as it does upstream. The upstream `javascript-comments` parser-legacy fixture is no longer skipped.
