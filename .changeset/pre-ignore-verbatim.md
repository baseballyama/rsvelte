Fix `<!-- prettier-ignore -->` being ignored by the `<pre>`/`<textarea>` sub-format's
re-indent pass. A node marked `prettier-ignore` nested inside a reformatted `<pre><code>`
block (e.g. one with an attribute and an element child, which triggers the hybrid
sub-format) had its own text and closing tag re-indented instead of staying byte-verbatim;
only the ignored node's own opening-tag line, whose indentation is generated by the
parent layout, is now touched.
