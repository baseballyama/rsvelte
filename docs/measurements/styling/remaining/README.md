# Remaining styling prerequisites

All 453 previously unparsed CSS units now parse and match Svelte 5.57.1.
The complete CSS population has 2,161 exact matches, no parse failures, and no differences.

Native typed trees now cover control flow, classes, generators, bigint literals,
dynamic imports, import attributes, module scripts, and the TypeScript forms used
by these units. Scope facts handle catch bindings, loop bindings, class names,
and module visibility. Client and server share tree copying and script lowering.
CSS fixes cover external nested rules, bare globals, declaration spans, and
specificity inside `:where`. Trees stay immutable; analysis uses side tables.

## CPU cycles

Hardware cycles and instructions come from `proc_pid_rusage(RUSAGE_INFO_V4)`
between stdin gates. Each arm warms 20 rounds and measures four trials of 1,000
rounds. Three-arm order is official/old/rewrite/rewrite/old/official twice.
Zero-round controls advance counters; measured rounds exceed those controls.
Inputs are loaded before the gates. One worker handles files in order.

| Median cycles per input | Official JS | Old Rust | Rewrite |
|---|---:|---:|---:|
| Common 18 | 1,037,977 | 500,982 | 55,319 |
| New 16 | 1,186,009 | 263,761 | 57,477 |

See [cycles-common.json](cycles-common.json) and [cycles-new.json](cycles-new.json).
The old Rust baseline is `5ed8ea3a3401b9fbbe780d3b18d6f90073291d6b`.
A separate before/after ABBA run on the common 18 gives 54,314 and 55,295 cycles
per input. Trial ranges overlap, so it shows no speed improvement.
See [cycles-before-after.json](cycles-before-after.json).
CPU frequency and affinity are not fixed. Other processes were active.
Official compilation includes source maps; native output omits them.
These earlier samples cover 18 and 16 components. The later
[453-unit measurement](../corpus-453/README.md) covers the full new CSS population. No result proves that this is the fastest possible implementation.

An isolated experiment restores temporary child `Vec` buffers in scope and
expression visitors. All other measured sources stay the same. On the new 16,
direct traversal reduces median cycles from 47,950 to 45,835 (4.4%) and median
instructions from 204,199 to 194,223 (4.9%) per input. Four trials per arm run in
ABBA order twice. See [visitor-cycles.json](visitor-cycles.json). These samples
were taken separately from the three-arm run; compare arms within each run.

## Memory

[layout.tsv](layout.tsv) records measured Rust sizes and alignment. New JavaScript
nodes use the existing columns: tag 1 byte, flags 1 byte, data 8 bytes, and position
8 bytes. The decoded `Kind` is 40 bytes; it is not stored once per node.
The evaluated `Value` is 24 bytes. Bigint data is boxed and does not enlarge the
common value layout. Common imports need no new record; import attributes add a
record only when present.

A separate binary counts one serial round after 20 warm rounds. It installs
`CountingAllocator`; CPU samples use the normal allocator.

| Population | Allocations | Requested bytes | Peak live heap growth |
|---|---:|---:|---:|
| Common 18 before | 3,863 | 330,127 | 47,183 |
| Common 18 after | 3,863 | 330,019 | 47,183 |
| New 16 | 2,593 | 152,646 | 22,365 |

See [allocations.json](allocations.json). The common population shows no material
heap improvement. One warm `vmmap` sample reports 2,608 KiB before and 2,640 KiB
after on the common population, and 1,936 KiB on the new population. Full maps
and summaries are saved here. These samples do not prove a footprint reduction.
Virtual reservations, dirty pages, and live heap growth are different quantities.

The visitor experiment reduces allocations from 2,996 to 2,593 (13.5%) and
requested bytes from 159,094 to 152,646 (4.1%) on the new 16. Peak live heap growth
stays at 22,365 bytes. See [visitor-allocations.json](visitor-allocations.json).
The optimized visitors use immutable child slices directly, with no temporary
child buffer. `raw.zip` contains the three changed variant sources and driver.

## Reproduction

[metadata.json](metadata.json) identifies the workspace commit, oracle version,
and every measured source file. `sources.zip` captures the dirty tree and its
measurement-only examples. `raw.zip` holds probes, drivers, counters, and checks.

```sh
cargo test --workspace
cargo clippy --all-targets -- -D warnings
cargo +nightly-2026-07-11 fmt --all --check
mise run structure
cargo run --release -p rsvelte_svelte_compile --example style_corpus -- \
  fixtures/svelte /tmp/styling.tsv --family --check
```
