# `destructure-in-a-statement-head-is-standalone.svelte`

**Issue:** shadow probe

Upstream decides whether a destructuring assignment keeps its value with `is_standalone = context.path.at(-1).type.endsWith('Statement')` — a **parent node type**. rsvelte answered it from the punctuation around the expression, which recognizes an expression statement and nothing else, so every statement whose child the assignment actually is got a trailing value: `if (({ v } = o))` came out `if (($.set(v, o.v, true), o))`, and where the right-hand side is cached the IIFE gained a `return $$value;` official does not emit. Ten head shapes (`if` / `while` / `do…while` / `switch` / three `for` slots / `return` / `throw`, plus the cached-RHS and array-pattern forms), three keyword-introduced statement bodies (`else`, `case …:`, `default:`) and a redundant paren layer, which acorn drops so the parent is the same one level out. `not_heads()` is the positive control and is the reason the rule is not just "a `)` follows": `if (1 && ({ v } = o))` closes on the same `)` and is a LogicalExpression's operand, as are `({ v } = o) && 1`, a sequence, a `const` initializer and a call argument — all five must keep the value. Ablated one sub-rule at a time over 132 comparisons: 22 head slots, 16 keyword bodies, 4 paren layers, 38 with the whole predicate removed. 0 of 34,728 corpus entries move.
