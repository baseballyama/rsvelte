# `pattern-default-declares-and-references.svelte`

**Issue:** shadow probe / corpus residue

**(shadow probe)** A destructured binding's DEFAULT is an ordinary expression, and upstream's `create_scopes` walks it: the arrow in `let { search = async (input) => … } = $props()` opens a scope and `scope.declare` puts `input` into `ScopeRoot.conflicts` (`phases/scope.js:698`), so `build_event`'s dev rename asks `scope.generate('input')` and gets `input_1`. `process_binding_pattern_typed` read the `AssignmentPattern`'s `left` and dropped its `right`, so nothing the default declares OR reads reached phase 2 at all and the handler came out as `function input()` (`svelte-material-ui/packages/autocomplete/src/Autocomplete.svelte`, `client-dev`). The default is walked AFTER the pattern, because the `$props()` arm applies `init_rune` to the `bindings[first_new..]` slice and an arrow parameter declared mid-pattern would land inside it. Object, array and nested-object rows are three shapes of the same slot. A function PARAMETER default was already right **for the wrong reason** — its `input` reached `root.conflicts` through the unbound-global collector in `2_analyze/mod.rs` — so the two slots had to be crossed to tell them apart. Ablated: 4 of 20 on the generated grid, 4 of 16 on the nested-host grid, 1 of 4 here. 1 of 34,728 corpus entries moves, toward official.

**(corpus residue)** Upstream's `create_scopes` walks a binding pattern's default like any other expression, so the arrow in `let { search = async (input) => … } = source` opens a scope and `scope.declare` puts `input` into `ScopeRoot.conflicts`; `build_event`'s dev rename then asks `scope.generate('input')` and gets `input_1`. `process_binding_pattern_typed` read the `AssignmentPattern`'s `left` and dropped its `right`, so the generated handler came out as `function input()`. The three rows cross the pattern's shape — object property, array element, nested object — because the walk is recursive and a fix that only handled the top level would pass on the first. This is the door the row above went through; the two were found independently and share a cause.
