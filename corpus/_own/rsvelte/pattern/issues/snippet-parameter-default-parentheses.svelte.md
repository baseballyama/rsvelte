# `snippet-parameter-default-parentheses.svelte`

**Issue:** [#4384](https://github.com/baseballyama/rsvelte/issues/4384)

Upstream reads a snippet's parameter list with `parse_expression_at` and never calls `remove_parens` on it (`1-parse/state/tag.js`), so a `ParenthesizedExpression` survives into `node.parameters` and is spread **verbatim** into the emitted function. Two decisions follow from that one omission and both are crossed here: esrap prints one pair per surviving node, and `is_simple_expression` — which has no arm for a paren node — takes the lazy `$.fallback(v, () => d, true)` arm however simple the contents are, so `(1)` and `(() => 1)` are not simple while `1` is. rsvelte unwrapped every paren at conversion, so both halves had to be recovered from the parameter's own source span, and the recovery counts pairs per node rather than setting a flag: `((obj.a))` prints two and a sequence's own brackets sit **inside** the source's, which is why `(obj.a, obj.a)` is `((obj.a, obj.a))` and not `(obj.a, obj.a)`. `bare`, `lit`, `unary` and `cond` are the controls that must gain nothing, and the parenthesized children — an array element, an object value, an arrow body, a `typeof` operand, a `??` right-hand side — pin that the pairs are restored where the source wrote them and not at the root. `memb` and `memb2` are the second reader of the same surviving node and the reason this is one fix and not two: upstream's `is_safe_identifier` walks a member chain by `node.object` and stops at a paren, so a paren on the **object** sets `analysis.needs_context` and the component gains `$.push`/`$.init`/`$.pop` — a phase-2 decision, invisible to a grid that compares the `$.fallback` line alone. It is snippet-parameter-only: `{(obj).a}` in a mustache, an attribute and an `{#each}` head are all no-push, because `remove_parens` runs on every other template expression. Neither shape occurs in the 33,891 collected components (a two-arm sweep over all four targets moves 2 units, both the sequence defaults in svelte's own `snippet-optional-arguments-defaults`), so this file is the whole detector.
