# `derived-name-as-a-destructured-parameter-default.svelte`

**Issue:** shadow probe

`function go({ v } = { v: 0 })` and `({ v } = obj)` spell the same bytes, and `destructure_transforms.rs` finds a destructuring assignment by scanning for `} =` / `] =`. Its one guard, `is_inside_enclosing_pattern`, answers "is this inside ANOTHER pattern" — a formal parameter list is not that — so a parameter default whose name is a `$derived` or a store was rewritten to `function go(($$value) => { v = $$value.v; return $$value; })({ v: 0 }) { … }`, **text no JS parser accepts**, with the component's own `$state` / `$derived` declarations left unlowered beside it. What separates the two spellings is the enclosing paren: a parameter list's `)` is followed by `=>` or by the body's `{`, and a control-flow head is the one other paren that closes before a `{`. The reach is the object pattern, the array pattern, a second parameter, an arrow, a class method and a `$y` store name — six rows, all client-only, because the server never runs this scanner and a template handler goes through the converter. `real_assignment()` performs a genuine destructuring assignment that must still be lowered, as the positive control; ablated, the file's output is rejected by acorn. 0 of 34,728 corpus entries move.
