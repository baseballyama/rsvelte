# `global-args-is-not-a-global-block.svelte`

**Issue:** corpus residue

Upstream reads "am I inside a global block" off `metadata.is_global_block`, which `is_global_block_selector` sets only for a BARE `:global` (`args === null`), so under `:global(.foo) { … }` the `(is_used(child) || is_in_global_block)` test in `is_empty` does not fire and a parent whose only child is unused is `(empty)`. rsvelte carries that one concept as two flags and the empty check read the one that ignores `args`, so the parent survived and only its child was commented. The template holds no element on purpose: a `&` under a fully-global parent matches every element, so one stray tag makes the nested `:global(i)` used and the shape stops discriminating. `&:hover` is the control for a declaration deciding non-emptiness on its own, `.local` is the control that rejects always passing the flag. Nothing can reject always passing `false`: inside a bare `:global` block no selector is ever marked unused, so the flag changes no `is_empty` answer there — measured, the site is reached 851 times over the CSS fixtures, the flag is true 14 times, and the two arguments disagree 0 times. `client` alone lists this shape because `targets.mjs` compares no CSS on either server target.
