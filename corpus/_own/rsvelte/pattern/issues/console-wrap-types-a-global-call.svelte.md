# `console-wrap-types-a-global-call.svelte`

**Issue:** evaluate probe

Upstream's `globals` table gives a global call a TYPE even when it folds nothing — `Math.random()` is NUMBER, not UNKNOWN — and `global_constants` makes `Math.PI` a known value. `shape_can_be_unknown` knew neither, so a dev `console.log` of any of them was wrapped where official emits the bare call. This is the first change in this campaign whose blast radius is not zero: it moves **1 of 34,728** corpus entries, and it moves it toward official — `ha-fusion`'s `const remainingSeconds = Math.round(remaining / 1000)`. `is_global_keypath` also had to stop matching a bare `Math.` prefix: with it, `Math.notAThing` is a global here and UNKNOWN upstream, which is invisible while the only consumer FOLDS (both answer unknown) and wrong the moment one reads the type. The shadow rows are the sharp edge — a `const Math = { … }` must disqualify the keypath, and it must do so **by scope**: a name-keyed lookup let one function's local `Math` silence every other function's real one, and phase 2 records function-locals in `root.bindings` so the analysis lookup had to be confined to the instance and module scopes. The same-function shadow is what defends the third hunk, building the const index with the reference set. Ablated: 8 comparisons for the call arm, 2 for the member arm, 1 for the index, 10 with both arms removed. Server output does not move.
